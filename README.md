# GAIA GUARD

畑を守るレトロ風ブラウザゲーム。鳥獣たちを傷つけず、やさしく山へ還す。

A retro-style browser game about defending farms. Guide wildlife safely back to the mountains — without harming them.

## 遊び方 / How to play

- スマホ：画面を指でなぞってドローンを動かす（ミサイルは自動発射）
- PC：WASDキーで移動、スペースで射撃（オート射撃も可）
- コインを拾ってドローンを強化し、農園を守る
- 各エリアの最後に「山のヌシ（ボス）」が登場。全5エリアでエンディング

## 特徴 / Features

- 全5エリア（農園→森→村→寺院→山岳）の右肩上がりの難易度
- ヌシ戦：回転する部分シールドを回り込んで隙を突く
- コンティニュー制（負けたエリアから再開）
- シールド・子機の購入によるドローン強化
- オープニング演出、死因表示、農園の危険警告

## 世界観 / World

「攻撃」ではなく「還す」。敵を倒すのではなく、理解し、誘導し、守る。
KORU（コル）——空と地上のあいだに立つ、ひとつの心の物語。
